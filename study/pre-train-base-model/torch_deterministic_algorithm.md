## 什么是Pytorch的Deterministic Algorithm

如下代码在torch上启动确定性算法，那么确定性算法是指什么？
```python
torch.manual_seed(42)
if device_type == "cuda":
    torch.cuda.manual_seed(42)
torch.use_deterministic_algorithms(True)
```

### Convolution（卷积）是什么
卷积的本质是`滑动窗口加权求和`，让固定窗口在数据上滑动并逐个求得加权和。
* Conv1d、Conv2d、Conv3d表示一维、二维、三维的卷积；
* ConvTranspose1d、 ConvTranspose2d、ConvTranspose3d表示一维、二维、三维的转置卷积；
* ReplicationPad1d、ReplicationPad2d、 ReplicationPad3d表示一维、二维、三维的复制填充卷积。

### Convolution计算
设输入为[1,2,3,4,5]，卷积核是[1,2,3]，那么对输入求卷积如下。
```
[1*1+2*2+3*3, 2*1+3*2+4*3, 3*1+4*2+5*3]
```
它可以进一步表示为矩阵乘法如下。
```
// 输入
      [1]
x  =  [2]
      [3]
      [4]
      [5]

// 卷积核
      [1 2 3 0 0]
W  =  [0 1 2 3 0]
      [0 0 1 2 3]

// 矩阵乘法
      [1 2 3 0 0]   [1]     [14]
y  =  [0 1 2 3 0] × [2]  =  [20]
      [0 0 1 2 3]   [3]     [26]
                    [4]
                    [5]
```
可见我们将1x5的输入转换为了1x3，具体来说是将n转为n-3+1，变短了。

### Convolution Transpose转置卷积
转置卷积和卷积正好是反过来的。如上我们将卷积写成矩阵乘法形式，转置卷积就是对W先做转置，
然后与输入相乘，得到的输出更长（将输入转换到更大空间）。
```
// 卷积核
       [1 0 0]
       [2 1 0]
Wᵀ  =  [3 2 1]
       [0 3 2]
       [0 0 3]

// 输入
      [14]
y  =  [20]
      [26]

// 矩阵乘法      
       [1 0 0]            [14]
       [2 1 0]            [48]
x' =   [3 2 1] × [14]  =  [108]  
       [0 3 2]   [20]     [112]
       [0 0 3]   [26]     [78]
```
* 卷积是将一个窗口压缩为一个数。
* 转置卷积是将一个数分散为一个窗口，再将重叠部分相加。比如y中的14、20、26在5个位置分别展开，然后叠加部分求和。
  * 14展开系数分别是：1、2、3、0、0；
  * 20展开系数分别是：0、1、2、3、0；
  * 26展开系数分别是：0、0、1、2、3；

### ReplicationPad计算
卷积计算存在一个问题：边缘的值被计算的次数相比中间的值要少。例如[1,2,3,4,5]，3在3个窗口的计算中都用到，而1和5
各自只在一个窗口的计算中用到。
为了解决这个问题，有了padding，就是在原始输入的外面补一圈值。例如下面的输入：
```
1 2 3
4 5 6
7 8 9
```
补一圈值后如下。
```
? ? ? ? ?
? 1 2 3 ?
? 4 5 6 ?
? 7 8 9 ?
? ? ? ? ?
```

这个 ? 应该填什么，就对应不同padding。
* Zero Padding：填0。
* ReplicationPad：复制边缘，即选择最近的一个值填进去。
```
1 1 2 3 3
1 1 2 3 3
4 4 5 6 6
7 7 8 9 9
7 7 8 9 9
```

### 维度
Conv1d、Conv2d、Conv3d：这里的一维、二维、三维表示的是窗口的维度。不论窗口是几维，卷积的计算方法都不变，
都是对应位置的值与参数乘积求和。


### Convolution计算的不确定性与确定性
卷积计算在前文中展开为矩阵乘法求和，这些乘法是并行计算的所以返回的顺序不确定。在数学中，加法满足交换律，
乱序相加没关系。但计算机中浮点数有精度（会舍弃一些小数位），于是乱序相加的结果就会不同。

为了实验可复现，torch支持卷积的确定性计算：即固定了相加的顺序，保证每次结果都一致。这在debug或论文中
都很有意义。
