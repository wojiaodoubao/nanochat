## 模型优化与梯度下降
我之前有2个概念没搞清：

1.模型和向量的关系？模型在学习的时候都是有逻辑结构的，包括神经元以及各种连接，它们
  和向量、矩阵有什么关系呢？Pytorch里头定义的模型结构究竟是什么，是实现了模拟神经
  元间连接的数据结构吗？还是用矩阵进行表示，为什么可以用矩阵表示呢？

2.梯度下降为什么可以逼近模型优化目标？我们以二元一次方程为例验证梯度下降逼近。带入
一个样本 x₀、y₀，我们得到 y₀ + loss₀ = ax₀ + b，这时候为什么沿着梯度方向就能
逼近 a、b 的真实值，以及 loss₀ 在这里起到了什么作用？如果 loss₀ 为 0，梯度仍然
可能不是 0，这时候要向什么方向去下降？

### 模型与向量
各种深度学习模型，从简单的linear到CNN、RNN再到transformer、GPT，虽然模型逻辑
结构不同，但最终都可以用矩阵运算的方式来描述，即：对于输入向量（或将输入embedding
为向量），经过一系列运算最终得到一个输出向量（或将输出向量decoding为最终输出）。
因此在模型表示中，并不需要真的构建模型的逻辑结构，只需要定义矩阵运算就可以。

为什么所有模型结构都可以简化为矩阵运算呢？因为如果不能简化，就会不方便GPU运算，
进而没办法做模型优化，也就办法验证。因此任何结构，包括transformer，在设计的时候
就要考虑如何计算，而且是如何高效的并行计算。

### 梯度下降与模型优化
这些矩阵运算又进一步等价于一组方程，参数矩阵对应方程中的参数。训练模型就是训练参数
矩阵中的参数值，也就是计算方程中的参数。

对于二元一次方程，只要有2个样本值就能联立求得参数值，也就是解析解。但是在大模型场景，
没办法直接求得解析解，因此是使用了一种逐步逼近的方式，也就是梯度下降。这个问题和
数理统计中通过一组样本估计参数分布有点像，只不过模型优化要的不是参数分布，而是具体
参数值。

下一个问题是：为什么沿梯度方向下降就是参数优化方向呢？就像上面问题2中说明那样？下面
是GPT给的回答，解释了这个问题。
> 这里最关键的误区是：
> 
> y₀ + loss₀ = ax₀ + b
> 
> 其中的 loss₀ 实际上更准确地叫做“残差”：
> 
> r₀ = ax₀ + b - y₀
> 
> 它可以为正也可以为负。而通常所说的平方损失是：
> 
> L₀ = ½r₀² = ½(ax₀ + b - y₀)²
> 
> 一、一个样本不能确定真实的 a、b
> 
> 对于一个样本 (x₀,y₀)，要求预测正确，只得到一个方程：
> 
> ax₀ + b = y₀
> 
> 但这里有两个未知数，因此存在无穷多组解。例如 x₀=2、y₀=5，那么：
> 
> 2a + b = 5
> 
> (a,b)=(0,5)、(1,3)、(2,1)…都能让损失为 0。
> 
> 所以，只用一个样本，梯度下降无法保证逼近真实的 a、b。它只能逼近直线 ax₀+b=y₀ 上的某一点。
> 
> 二、梯度为什么指向正确的下降方向？
> 
> 对平方损失求梯度：
> 
> ∂L₀/∂a = r₀x₀
> ∂L₀/∂b = r₀
> 
> 因此：
> 
> ∇L₀ = r₀(x₀,1)
> 
> 梯度下降实际沿着负梯度方向更新：
> 
> a_new = a - ηr₀x₀
> b_new = b - ηr₀
> 
> 残差 r₀ 提供两类信息：
> 
> 1. 正负号：预测是偏大还是偏小；
> 2. 绝对值：偏差有多大，参数需要调整多少。
> 
> 如果 r₀>0，说明预测值 ax₀+b 偏大，就要向降低预测值的方向调整；如果 r₀<0，则反向调整。
> 
> 从几何上看，(x₀,1) 是参数空间中直线 ax₀+b=y₀ 的法向量。因此负梯度会把当前的 (a,b) 推向这条“零损失直线”，但不能确定直线上的哪一点才是真实参数。
> 
> 三、如果残差为 0，梯度是什么？
> 
> 如果 r₀=ax₀+b-y₀=0，那么平方损失为 0，并且：
> 
> ∇L₀ = r₀(x₀,1) = (0,0)
> 
> 因此对这个样本而言，损失为 0 时梯度必然为 0，不需要再向任何方向下降。
> 
> 如果得到“loss 为 0，但梯度不为 0”，通常可能是：
> 
> 1. 把残差本身当成了损失。如果定义 L₀=ax₀+b-y₀，则 ∇L₀=(x₀,1)，即使 L₀=0，梯度也可能不为 0。但这个目标可以不断变成负数，没有最小值，因此不是合适的误差度量。平方损失则非负，并且预测完全正确时梯度为 0。
> 
> 2. 单个样本损失为 0，但总损失不为 0。多样本训练的总损失为：
> 
> L(a,b) = (1/2n)Σᵢ(axᵢ+b-yᵢ)²
> 
> 总梯度为：
> 
> ∂L/∂a = (1/n)Σᵢrᵢxᵢ
> ∂L/∂b = (1/n)Σᵢrᵢ
> 
> 即使第 0 个样本满足 r₀=0，其他样本仍可能使总梯度不为 0。这时应沿着总损失的负梯度下降。更新后，第 0 个样本甚至可能暂时不再完全拟合，但全部样本的总损失会下降。
> 
> 四、多个样本为什么可能确定真实参数？
> 
> 如果有两个不同的输入：
> 
> ax₀+b=y₀
> ax₁+b=y₁，且 x₀≠x₁
> 
> 那么在没有噪声时，两条参数约束直线会相交于唯一一点：
> 
> a* = (y₁-y₀)/(x₁-x₀)
> b* = y₀-a*x₀
> 
> 每个样本的梯度都把参数推向各自的零损失直线；总损失综合所有样本，形成一个以 (a*,b*) 为最低点的“碗”。学习率合适时，梯度下降会逐步逼近这个最低点。
> 
> 结论：残差告诉我们预测偏差的方向和大小，平方损失把它转化为可最小化的目标。单个样本只能让参数逼近一条零损失直线；足够多且信息独立的样本，才可能让梯度下降逼近唯一的真实 a、b。
